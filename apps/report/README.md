# @vault-verify/report

Screening report app (Vite + React + Tailwind): fixture-driven overall score,
verification badge, per-criterion cards, session timeline, and an in-browser
"Verify this log" panel. No database connection yet.

- `npm run dev -w @vault-verify/report` — local preview
- `npm run build -w @vault-verify/report` — production bundle
- `npm run fixtures -w @vault-verify/scoring` — regenerate `src/fixtures/`
